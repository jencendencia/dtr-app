# Feature: Per-Teacher Training Registration

## Overview

Add a "Training" feature where admins can register training periods for specific teachers. During training dates, teachers cannot login/logout. Training days appear in attendance records and the printed DTR similar to holidays/suspensions.

## Database Schema

### New Table: `Trainings`

```sql
CREATE TABLE IF NOT EXISTS Trainings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  teacher_id INTEGER NOT NULL,
  start_date TEXT NOT NULL,      -- 'YYYY-MM-DD'
  end_date TEXT NOT NULL,        -- 'YYYY-MM-DD' (inclusive)
  description TEXT DEFAULT '',
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (teacher_id) REFERENCES Teachers(id) ON DELETE CASCADE
)
```

Add migration in `src/db/connection.js` after the existing migrations (after line 62).

## IPC Handlers (src/main/main.js)

### 1. `add-training` (new)
- Input: `{ teacher_id, start_date, end_date, description }`
- Validates: teacher exists, start_date <= end_date, no overlapping training for same teacher
- Inserts into Trainings table
- Returns `{ success, id }`

### 2. `get-trainings-for-teacher` (new)
- Input: `teacherId, month, year`
- Queries Trainings WHERE teacher_id = ? AND training overlaps with the month range
- Returns array of `{ id, start_date, end_date, description }`

### 3. `delete-training` (new)
- Input: `trainingId`
- Deletes from Trainings table
- Returns `{ success }`

### 4. Modify `get-holidays-for-dtr` (existing, line 1458)
- Also accept an optional `teacherId` parameter
- If teacherId provided, also fetch trainings for that teacher
- Merge training dates into the returned map with `type: 'training'`
- This way `displayTeacherLogs()` and `generateDTRHtml()` can handle training in the same code path as holidays
